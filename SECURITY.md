# Security policy

## Reporting a problem

Please do not report security problems in public issues.

Use GitHub's private vulnerability reporting (the **Report a vulnerability** button on the Security tab of this repository), or email support@froala.com with "Security" in the subject.

Please include what you found, how to reproduce it and which version you used. We confirm that we received your report and keep you updated while we work on a fix.

## Supported versions

Security fixes go into the latest release.

## What the server does with your data

The tools only read data that ships with the server. They do not change files, run the code you send or call other services.
