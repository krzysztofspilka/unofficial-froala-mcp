# Security policy

## Reporting a problem

Please don't report security problems in public issues.

Use GitHub's private vulnerability reporting (the **Report a vulnerability** button on the Security tab of this repository), or email support@froala.com with "Security" in the subject.

Please include what you found, how to reproduce it and which version you used. We'll confirm that we received your report and keep you updated while we work on a fix.

## Supported versions

Security fixes go into the latest release. The hosted server at https://mcp.froala.com/mcp always runs the latest release.

## What the server does with your data

The tools only read data that ships with the server. They don't change files, run the code you send or call other services. The hosted server doesn't store the code or questions sent to it. For statistics it records only the tool name, whether the call worked, how long it took, the country and the client's user agent.
